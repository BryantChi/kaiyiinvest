# 楷懿國際投資 Kaiyi International Investment

多語系企業官網與後台內容管理系統。深耕越南河內、海防市場，提供工業地產、不動產代理與專業諮詢服務。

- 正式網域：[kaiyiinvest.com](https://kaiyiinvest.com)
- 支援語系：繁體中文（預設）、English、Tiếng Việt（越南文）

## 功能

**前台官網**
- 首頁、關於我們、服務項目、工業區開發、包租代管、合作夥伴、常見問答、聯絡我們
- 三語系切換，依訪客來源自動判斷語言
- 每頁每語系獨立 SEO（含 Sitemap、結構化資料）
- 聯絡表單（具防灌水與通知信）

**後台管理**
- 文章 / 分類 / 標籤、常見問答
- 頁面文案逐語系編輯
- 語系管理、SEO 設定
- 聯絡訊息、使用者與權限、一般與郵件設定、活動日誌

## 技術

Laravel 11 / PHP 8.2、MySQL、Blade 模板。
